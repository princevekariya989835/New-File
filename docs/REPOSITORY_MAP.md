## 2. Root Configuration & Project Files

### `package.json`
- **Role**: Project configuration, dependencies, and build scripts.
- **Key Scripts**: `npm run dev` (Vite dev server), `npm run build` (Prebuild + Vite build + Copy dist), `npm run start` (Run server bundle).
- **Type**: Configuration.
- **Risk**: Modifying dependencies or versions can break Cloudflare Workers or TanStack Start build pipelines.

### `wrangler.json`
- **Role**: Cloudflare Workers deployment configuration.
- **Key Bindings**:
  - `main`: `.output/server/index.mjs`
  - `assets`: Directory `.output/public` bound to `ASSETS`
  - `d1_databases`: `riotous-db` (Database ID `7487ac0f-706e-4560-baf8-e79031b2dd5e`)
  - `vars`: `EMAIL_FROM`, `EMAIL_MODE`, `ZIPPYY_BASE_URL`, `ZIPPYY_PICKUP_PINCODE`, `ZIPPYY_LOCATION_ID`, `ZIPPYY_DEFAULT_WAREHOUSE_ID`
- **Type**: Cloudflare Configuration.
- **Risk**: Renaming database bindings or altering compatibility dates breaks production edge hosting.

### `vite.config.ts`
- **Role**: Vite 8 bundler configuration integrating React 19, Tailwind CSS v4, TanStack Start, and Nitro.
- **Key Plugins**: `@tailwindcss/vite`, `tanstackStart()`, `nitro({ preset: 'cloudflare_module' })`, `viteReact()`.
- **Route Rules**: Enforces caching headers for `/assets/**`, `/products/**`, `/api/media/**`, and `no-store` for `/_server/**` and `/api/**`.
- **Type**: Configuration.

### `tsconfig.json`
- **Role**: TypeScript compiler configuration, path aliases (`@/*` pointing to `./src/*`).
- **Type**: Configuration.

## 3. Server & Routing Core (`src/`)

### `src/server.ts`
- **Role**: Production Cloudflare Worker entry point and HTTP pipeline.
- **Exports**: `default.fetch(request, env, ctx)`.
- **Responsibilities**:
  1. Injects Cloudflare environment (`setCloudflareEnv(env)`).
  2. Normalizes apex domain (`www.riotous.store` -> `riotous.store`).
  3. Permanently redirects legacy catalog URLs (`/products`, `/collections`, etc.) to `/shop`.
  4. Strips trailing slashes to eliminate duplicate URLs.
  5. Attaches CSP, HSTS, X-Frame-Options, X-Content-Type-Options, and conditional `X-Robots-Tag: noindex, nofollow`.
- **Type**: Application Code (Critical Entry Point).
- **Risk**: High. Any syntax or runtime error halts all incoming traffic.

### `src/client.tsx`
- **Role**: Client-side hydration entry point.
- **Exports**: Hydration call for `@tanstack/react-start/client`.
- **Type**: Application Code.

### `src/router.tsx`
- **Role**: Creates and configures the TanStack Router instance.
- **Dependencies**: `src/routeTree.gen.ts`.
- **Type**: Application Code.

### `src/routeTree.gen.ts`
- **Role**: Auto-generated route tree generated by TanStack Router from the files inside `src/routes/`.
- **Type**: Generated Code.
- **Notice**: Do NOT edit manually; regenerated on `vite dev` or `vite build`.

### `src/styles.css`
- **Role**: Master CSS file using Tailwind CSS v4 with `@theme` token definitions (`--color-brand-red: #F00B11`, custom font families, animations).
- **Type**: Styling.

## 4. Route Handlers (`src/routes/`)

## 5. Backend Libraries & Server Functions (`src/lib/`)

### 5.1 Database & Core Infrastructure
- **`src/lib/db.ts`**: Universal database layer. Automatically selects Cloudflare D1 (`env.DB`), Neon PostgreSQL (`DATABASE_URL`), or in-memory mock engine.
- **`src/lib/server-logger.ts`**: Structured server event logging for sync events, database errors, and cache invalidation.
- **`src/lib/error-capture.ts` & `src/lib/error-page.ts`**: Intercepts unhandled SSR errors and outputs branded error pages.

### 5.2 Catalog, Products & Inventory
- **`src/lib/catalog.ts`**: Core catalog service. Maps relational database rows to storefront product structures, manages `_productsCache` (2s burst debounce), and exports `invalidateCatalogCache()`.
- **`src/lib/fallback-products.ts`**: Seed dataset containing initial streetwear products, garment measurements, and default variants.
- **`src/lib/inventory.service.ts`**: Inventory stock deduction, reservation release, restocking, and transaction audit logs.
- **`src/lib/product-images.ts`**: Image caching and streaming utilities.

### 5.3 Authentication & Authorization
- **`src/lib/auth.ts`**: Client and shared authentication utilities (login, signup, OTP).
- **`src/lib/auth.server.ts`**: Server-side JWT token generation, cryptographic signature validation, and password hashing.
- **`src/lib/auth.types.ts`**: TypeScript definitions for `AuthUser`, `StaffRole`, and optimistic token claim parsing.
- **`src/lib/auth-middleware.ts`**: TanStack Start middleware (`requireAuth`) validating tokens against the `profiles` table.

### 5.4 Orders, Invoices & Checkout
- **`src/lib/orders.functions.ts`**: Server functions for order placement, status updates, address validation, and order lookup.
- **`src/lib/invoice.functions.ts`**: Generation of GST-compliant tax invoices and sequence numbering.
- **`src/lib/coupons.functions.ts`**: Coupon validation, discount computation, and usage incrementing.
- **`src/lib/razorpay.server.ts`**: Razorpay client for creating orders and verifying payment signatures.

### 5.5 Logistics & External Services
- **`src/lib/zippyy/*`**:
  - `client.ts`: Zippyy API client with OAuth2 token caching and automatic refresh on 401.
  - `shipment.service.ts`: Shipment creation, AWB assignment, and courier tracking polling.
  - `types.ts`: Zippyy payload and response type definitions.
- **`src/lib/email/*`**: Email sending implementations using Brevo and Resend APIs.
- **`src/lib/email-templates/*`**: React Email templates for order confirmation, shipment dispatch, and customer notifications.
